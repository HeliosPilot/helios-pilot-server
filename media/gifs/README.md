# HELIOS-NET GIF Media

This directory contains GIF images used for Telegram bot responses in the HeliosPilot project.

## Usage

GIFs can be used to enhance Telegram bot messages with visual reactions and animations.

## Adding New GIFs

1. Place your GIF files in this directory
2. Reference them in the Telegram service code using their filename
3. Supported formats: GIF (animated or static)

## Current GIFs

- Add your GIF files here with descriptive names
- Example: `welcome.gif`, `success.gif`, `error.gif`, `thinking.gif`

## Notes

- Keep file sizes reasonable (< 2MB recommended for Telegram)
- Use lowercase filenames with hyphens for spaces
- Update the Telegram service to handle GIF sending if needed
